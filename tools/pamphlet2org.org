* Abstract

This tool converts Axiom's =.pamphlet= files (LaTeX-based literate
programming) to Emacs =.org= format.  The org file can then be tangled
to produce the same code output as =tanglec=, enabling GitHub preview
and unified tooling under org-mode.

The mapping is straightforward because both systems share the same
core idea: *named code blocks that reference each other*.

* Why org-mode

| Feature          | Pamphlet (LaTeX + tanglec) | Org (org-babel + noweb)  |
|------------------+----------------------------+--------------------------|
| Named chunks     | ~\begin{chunk}{name}~     | ~#+NAME: name~           |
| Chunk inclusion  | ~\getchunk{name}~         | ~<<name>>~ (noweb)       |
| Concatenation    | Same name = append         | Same name = append       |
| GitHub preview   | No (plain text)            | Yes (rendered HTML)      |
| Editor support   | LaTeX mode                 | org-mode (folding, etc)  |
| Tangling tool    | ~tanglec~ (custom C)       | ~org-babel-tangle~ (built-in) |

The org format preserves every piece of information in the pamphlet
while gaining GitHub rendering, org-mode folding, and built-in
tangling — no external tools needed.

* Design

** Pamphlet chunk → org source block

#+begin_example
,\begin{chunk}{name}          →  ,#+NAME: name
  code here                    →  ,#+BEGIN_SRC lang :noweb yes
,\end{chunk}                   →    code here
                                →  ,#+END_SRC
#+end_example

Multiple chunks with the same name are concatenated by both systems.

** getchunk → noweb reference

#+begin_example
,\getchunk{name}              →  <<name>>
#+end_example

Both tanglec and org-babel expand these recursively.

** Language detection

The language for =#+BEGIN_SRC= is inferred from:
1. The chunk name suffix (e.g. =foo.lisp= → =common-lisp=)
2. The file extension (e.g. =.boot= → =boot=)
3. Default: =common-lisp=

** Prose conversion

| LaTeX              | Org           |
|--------------------+---------------|
| ~\section{Foo}~    | ~* Foo~       |
| ~\subsection{Bar}~ | ~** Bar~      |
| ~\verb|x|~         | ~=x=~         |
| ~\emph{x}~         | ~/x/~         |
| ~{\bf x}~          | ~*x*~         |
| ~\file{x}~         | ~=x=~         |
| ~$math$~           | ~\(math\)~    |

** Language detection

#+BEGIN_SRC elisp
(defun pamphlet2org--detect-lang (chunk-name filename)
  "Infer source block language from CHUNK-NAME and FILENAME."
  (let ((ext (file-name-extension filename)))
    (cond
     ;; Chunk named "*" — use file extension
     ((string= chunk-name "*")
      (pcase ext
        ("lisp" "common-lisp")
        ("boot" "boot")
        ("spad" "spad")
        ("input" "axiom-input")
        ("c" "c")
        ("h" "c")
        (_ "common-lisp")))
     ;; Try chunk name suffix
     ((string-suffix-p ".lisp" chunk-name) "common-lisp")
     ((string-suffix-p ".boot" chunk-name) "boot")
     ((string-suffix-p ".spad" chunk-name) "spad")
     ((string-suffix-p ".input" chunk-name) "axiom-input")
     ((string-suffix-p ".c" chunk-name) "c")
     ((string-suffix-p ".h" chunk-name) "c")
     ;; Fall back to file extension
     (t (pcase ext
          ("lisp" "common-lisp")
          ("boot" "boot")
          ("spad" "spad")
          ("input" "axiom-input")
          ("c" "c")
          ("h" "c")
          (_ "common-lisp"))))))
#+END_SRC

** Inline LaTeX → org markup

This handles prose lines outside of code chunks.  Code inside chunks
is passed through verbatim — no conversion.

#+BEGIN_SRC elisp
(defun pamphlet2org--convert-line (line)
  "Convert inline LaTeX in LINE to org markup."
  (let ((s line))
    ;; \verb|...| or \verb'...' → ~...~
    (setq s (replace-regexp-in-string
             "\\\\verb|\\([^|]*\\)|" "~\\1~" s))
    (setq s (replace-regexp-in-string
             "\\\\verb'\\([^']*\\)'" "~\\1~" s))
    ;; \file{...} → =...=
    (setq s (replace-regexp-in-string
             "\\\\file{\\([^}]*\\)}" "=\\1=" s))
    ;; \emph{...} → /.../
    (setq s (replace-regexp-in-string
             "\\\\emph{\\([^}]*\\)}" "/\\1/" s))
    ;; {\bf ...} → *...*
    (setq s (replace-regexp-in-string
             "{\\\\bf \\([^}]*\\)}" "*\\1*" s))
    ;; \texttt{...} → =...=
    (setq s (replace-regexp-in-string
             "\\\\texttt{\\([^}]*\\)}" "=\\1=" s))
    ;; $...$ (inline math) → \(...\)
    (setq s (replace-regexp-in-string
             "\\([^$]\\)\\$\\([^$]+\\)\\$\\([^$]\\)"
             "\\1\\\\(\\2\\\\)\\3" s))
    (setq s (replace-regexp-in-string
             "^\\$\\([^$]+\\)\\$"
             "\\\\(\\1\\\\)" s))
    s))
#+END_SRC

** Core converter

The converter is a line-by-line state machine with these states:
- *preamble* — before ~\begin{document}~, extracting title/author
- *prose* — outside chunks, converting section headings and inline LaTeX
- *chunk* — inside ~\begin{chunk}~...~\end{chunk}~, collecting code lines
- *verbatim* — inside ~\begin{verbatim}~...~\end{verbatim}~
- *bibliography* — inside ~\begin{thebibliography}~

Chunk lines are collected separately and reversed at chunk-end to
preserve original order (we =push= to a list during traversal).

#+BEGIN_SRC elisp
(defvar pamphlet2org--src-prefix (concat "#" "+")
  "Org #+ prefix, split to avoid literate-elisp misparse.")

(defun pamphlet2org--convert (pamphlet-text filename)
  "Convert PAMPHLET-TEXT (string) to org format.
FILENAME is used for language detection.
Returns the org text as a string."
  (with-temp-buffer
    (insert pamphlet-text)
    (goto-char (point-min))
    (let ((result '())
          (in-preamble t)
          (in-chunk nil)
          (chunk-name nil)
          (in-verbatim nil)
          (in-bib nil)
          (chunk-lines '()))

      (while (not (eobp))
        (let* ((line (buffer-substring-no-properties
                      (line-beginning-position) (line-end-position)))
               (trimmed (string-trim line)))

          (cond
           ;; ---- End of document (only outside chunks; chunk code may
           ;;      carry the literal string) ----
           ((and (not in-chunk) (string= trimmed "\\end{document}"))
            (goto-char (point-max)))

           ;; ---- Preamble: extract title/author ----
           (in-preamble
            (cond
             ((string-match "^\\\\title{\\(.*\\)}" line)
              (let ((title (match-string 1 line)))
                (setq title (string-remove-suffix "}" title))
                (setq title (replace-regexp-in-string "\\\\\\$" "$" title))
                (push (format "%sTITLE: %s" pamphlet2org--src-prefix title) result)))
             ((string-match "^\\\\author{\\(.*\\)}" line)
              (let ((author (match-string 1 line)))
                (setq author (string-remove-suffix "}" author))
                (push (format "%sAUTHOR: %s" pamphlet2org--src-prefix author) result)))
             ((string= trimmed "\\begin{document}")
              (setq in-preamble nil)
              (push "" result))
             ;; Book volumes \input{bookheader.tex} (which holds
             ;; \begin{document}); they carry none of their own.  Leave
             ;; the preamble at the first content marker and re-read this
             ;; line so it is processed as content rather than skipped.
             ((or (string= trimmed "\\mainmatter")
                  (string-match-p "^\\\\chapter{" trimmed)
                  (string-match-p "^\\\\begin{chunk}{" trimmed))
              (setq in-preamble nil)
              (forward-line -1))))

           ;; ---- Verbatim blocks (prose only; never inside a chunk) ----
           (in-verbatim
            (cond
             ;; lenient end: \end{verbatim} may be glued to text, e.g.
             ;; ";   v\end{verbatim}"
             ((string-suffix-p "\\end{verbatim}" trimmed)
              (push (concat pamphlet2org--src-prefix "END_EXAMPLE") result)
              (setq in-verbatim nil))
             ;; a chunk start must never be swallowed by an unclosed
             ;; verbatim — close the block and re-read the line as a chunk
             ((string-match-p "^\\\\begin{chunk}{" trimmed)
              (push (concat pamphlet2org--src-prefix "END_EXAMPLE") result)
              (setq in-verbatim nil)
              (forward-line -1))
             (t (push line result))))
           ((and (not in-chunk) (string= trimmed "\\begin{verbatim}"))
            (push (concat pamphlet2org--src-prefix "BEGIN_EXAMPLE") result)
            (setq in-verbatim t))

           ;; ---- Chunk start ----
           ((and (not in-chunk)
                 (string-match "^\\\\begin{chunk}{\\(.+\\)}" trimmed))
            (setq chunk-name (match-string 1 trimmed))
            (let ((lang (pamphlet2org--detect-lang chunk-name filename)))
              (push "" result)
              (push (format "%sNAME: %s" pamphlet2org--src-prefix chunk-name) result)
              (push (format "%sBEGIN_SRC %s :noweb yes" pamphlet2org--src-prefix lang) result))
            (setq in-chunk t)
            (setq chunk-lines '()))

           ;; ---- Chunk end ----
           ((and in-chunk (string= trimmed "\\end{chunk}"))
            (dolist (cl (nreverse chunk-lines))
              (push cl result))
            (push (concat pamphlet2org--src-prefix "END_SRC") result)
            (push "" result)
            (setq in-chunk nil)
            (setq chunk-name nil)
            (setq chunk-lines '()))

           ;; ---- getchunk reference ----
           ((string-match "^\\\\getchunk{\\(.+\\)}" trimmed)
            (let ((ref (match-string 1 trimmed)))
              (push (format "<<%s>>" ref)
                    (if in-chunk chunk-lines result))
              ;; tanglec-compat quirk: tanglec advances a fixed offset
              ;; past \getchunk{name}, so trailing text after } leaks the
              ;; remainder (minus its first byte) as an extra output line
              ;; (a lone trailing space => one extra blank line).
              (when (string-match "}\\(.+\\)\\'" line)
                (push (substring (match-string 1 line) 1)
                      (if in-chunk chunk-lines result)))))

           ;; ---- Inside chunk: collect verbatim ----
           (in-chunk
            (push line chunk-lines))

           ;; ---- Outside chunk: prose ----

           ;; Section headings
           ((string-match "^\\\\subsubsection{\\(.+\\)}" line)
            (push (format "*** %s" (match-string 1 line)) result))
           ((string-match "^\\\\subsection{\\(.+\\)}" line)
            (push (format "** %s" (match-string 1 line)) result))
           ((string-match "^\\\\section{\\(.+\\)}" line)
            (push (format "* %s" (match-string 1 line)) result))

           ;; Bibliography
           ((string-match-p "^\\\\begin{thebibliography}" trimmed)
            (setq in-bib t)
            (push "* Bibliography" result))
           ((string= trimmed "\\end{thebibliography}")
            (setq in-bib nil))
           (in-bib
            (when (string-match "^\\\\bibitem{\\([^}]+\\)}\\s-*\\(.*\\)" line)
              (push (format "- [%s] %s"
                            (match-string 1 line)
                            (match-string 2 line))
                    result)))

           ;; Skip LaTeX structural commands
           ((member trimmed '("\\maketitle" "\\tableofcontents" "\\eject"
                              "\\begin{abstract}" "\\end{abstract}"
                              "\\begin{document}"))
            nil)

           ;; Default: prose line with inline conversion
           (t
            (push (pamphlet2org--convert-line line) result))))

        (forward-line 1))

      ;; Assemble (result was built in reverse via push)
      ;; Do NOT collapse blank runs — tanglec prints every line verbatim,
      ;; so squeezing chunk-internal blank lines would diverge from it.
      (let ((output (mapconcat #'identity (nreverse result) "\n")))
        (if (string-suffix-p "\n" output) output
          (concat output "\n"))))))
#+END_SRC

** File-level entry point

#+BEGIN_SRC elisp
(defun pamphlet2org-convert-file (pamphlet-file &optional org-file)
  "Convert PAMPHLET-FILE to ORG-FILE.
If ORG-FILE is nil, replaces .pamphlet extension with .org."
  (interactive "fPamphlet file: ")
  (let* ((pamphlet-text (with-temp-buffer
                          (insert-file-contents pamphlet-file)
                          (buffer-string)))
         (filename (file-name-nondirectory pamphlet-file))
         (target (or org-file
                     (concat (file-name-sans-extension pamphlet-file) ".org")))
         (org-text (pamphlet2org--convert pamphlet-text filename)))
    (with-temp-file target (insert org-text))
    (message "Converted %s -> %s" pamphlet-file target)
    target))
#+END_SRC

* Org Tangler

The tangler mirrors =tanglec= behavior: collect all source blocks by
name, concatenate blocks with the same name, then recursively expand
=<<name>>= references.

** Collect blocks

#+BEGIN_SRC elisp
(defun pamphlet2org--collect-blocks (org-file)
  "Return a hash of chunk-name -> concatenated body from ORG-FILE.
Scan #+NAME:/#+BEGIN_SRC...#+END_SRC line by line rather than via
`org-element': org parses a prose \\begin{enumerate} (or any LaTeX
environment) as a `latex-environment' that swallows the chunk blocks
nested inside it, so org-element would silently drop those chunks.
Same-named blocks are concatenated, mirroring tanglec."
  (let ((blocks (make-hash-table :test #'equal))
        (case-fold-search t))
    (with-temp-buffer
      (insert-file-contents org-file)
      (goto-char (point-min))
      (while (not (eobp))
        (cond
         ((looking-at "^#\\+NAME: \\(.*\\)$")
          (let ((name (string-trim (match-string-no-properties 1))))
            (forward-line 1)
            (when (looking-at-p "^#\\+BEGIN_SRC")
              (forward-line 1)
              (let ((start (point)))
                (while (and (not (eobp)) (not (looking-at-p "^#\\+END_SRC")))
                  (forward-line 1))
                (puthash name
                         (concat (gethash name blocks "")
                                 (buffer-substring-no-properties start (point)))
                         blocks)
                (unless (eobp) (forward-line 1))))))
         ((looking-at-p "^#\\+BEGIN_SRC")
          (forward-line 1)
          (while (and (not (eobp)) (not (looking-at-p "^#\\+END_SRC")))
            (forward-line 1))
          (unless (eobp) (forward-line 1)))
         (t (forward-line 1)))))
    blocks))
#+END_SRC

** Expand noweb references

Single-pass DFS that emits straight into one output buffer, mirroring
=tanglec= exactly: a =<<name>>= reference alone on a line is replaced by
NAME's expansion (nothing when NAME is undefined, matching tanglec which
drops dangling getchunks); every other line prints verbatim.  Writing to
a shared buffer instead of returning/splicing strings makes this O(output)
rather than O(output × depth) — the giant book volumes (≈1&nbsp;MB of
tangled output) drop from minutes to well under a second.

#+BEGIN_SRC elisp
(defun pamphlet2org--emit (body blocks prefix visiting out)
  "Emit the expansion of chunk BODY into buffer OUT.
PREFIX is the accumulated indentation prepended to every non-empty line;
VISITING is the cycle-detection set (a name currently being expanded is
left literal, as tanglec would otherwise loop)."
  (with-temp-buffer
    (insert body)
    (goto-char (point-min))
    (while (not (eobp))
      (let* ((eol (line-end-position))
             (line (buffer-substring-no-properties
                    (line-beginning-position) eol))
             (has-nl (< eol (point-max))))
        (if (string-match "\\`\\(\\s-*\\)<<\\([^>]+\\)>>\\s-*\\'" line)
            (let* ((j (match-string 1 line))
                   (ref (string-trim (match-string 2 line)))
                   (cycle (gethash ref visiting))
                   (def (and (not cycle) (gethash ref blocks))))
              (cond
               ;; defined: splice the chunk's expansion (no extra newline)
               (def
                (puthash ref t visiting)
                (pamphlet2org--emit def blocks (concat prefix j) visiting out)
                (remhash ref visiting))
               ;; cycle: keep the reference literal
               (cycle
                (with-current-buffer out
                  (when (> (length line) 0) (insert prefix))
                  (insert line)
                  (when has-nl (insert "\n"))))
               ;; undefined: tanglec drops the whole reference line
               (t nil)))
          (with-current-buffer out
            (when (> (length line) 0) (insert prefix))
            (insert line)
            (when has-nl (insert "\n")))))
      (forward-line 1))))
#+END_SRC

** Tangle entry point

#+BEGIN_SRC elisp
(defun pamphlet2org--tangle (org-file &optional chunk-name)
  "Tangle ORG-FILE, extracting CHUNK-NAME (default \"*\").
Mirrors tanglec: concatenate same-name blocks, expand <<ref>>.
Returns the tangled code as a string."
  (let* ((blocks (pamphlet2org--collect-blocks org-file))
         (target (or chunk-name "*"))
         (body (gethash target blocks)))
    (unless body (error "Chunk %S not found in %s" target org-file))
    (let ((out (generate-new-buffer " *pamphlet2org-tangle*"))
          (visiting (make-hash-table :test #'equal)))
      (unwind-protect
          (progn (pamphlet2org--emit body blocks "" visiting out)
                 (with-current-buffer out (buffer-string)))
        (kill-buffer out)))))
#+END_SRC

* Verification Pipeline

To verify that the conversion is correct:

#+begin_example
# 1. Tangle pamphlet (reference)
tanglec cfuns.lisp.pamphlet > /tmp/ref.txt

# 2. Convert pamphlet → org
emacs --batch -l pamphlet2org.org \
  --eval '(pamphlet2org-convert-file "cfuns.lisp.pamphlet")'

# 3. Tangle org (test)
emacs --batch -l pamphlet2org.org \
  --eval '(with-temp-file "/tmp/test.txt"
            (insert (pamphlet2org--tangle "cfuns.lisp.org")))'

# 4. Compare
diff /tmp/ref.txt /tmp/test.txt
#+end_example

If =diff= produces no output, the conversion is byte-identical.
