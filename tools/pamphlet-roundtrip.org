* Overview

A *byte-reversible* pamphlet <-> org pair, the basis for migrating the
Axiom sources to org as the single source of truth: we must be able to
rebuild the exact =.pamphlet= (hence the exact PDF) from the =.org=.

The design that makes the round trip provable by a mere =cmp=:

- Transform ONLY the chunk scaffolding -- =\begin{chunk}{name}= <->
  =#+NAME: name= + =#+begin_src LANG :noweb yes=, =\end{chunk}= <->
  =#+end_src=, =\getchunk{name}= <-> =<<name>>=.
- Emit *every other line verbatim* (prose, preamble, headings, verbatim,
  bibliography, structural markers).  Identity is trivially reversible.
- No added/removed blank lines.

So =to-pamphlet(to-org(P)) == P= byte-for-byte for the clean majority;
edge cases (malformed markers, trailing text) are handled as we find them.

* Phase 1: org-native headings (reversible prose rewrite)

Only the chunk scaffolding HAD to move to org; the prose stayed raw LaTeX.
Phase 1 makes the *headings* org-native too -- =\chapter{X}= <-> =* X=,
=\section= <-> =**=, =\subsection= <-> =***=, =\subsubsection= <-> =****= --
while staying byte-reversible.  Two rules keep it a true bijection:

- Convert ONLY a bare =^\section{X}$= line; a heading with trailing text
  (=\section{X}\label{..}=) stays verbatim.
- A prose line that is zero-or-more commas then =*= would be read back as a
  heading (or an already-escaped one), so escape it with a leading comma --
  org's own =,*= convention.  The reverse strips exactly one comma.

Applied to PROSE only: chunk code and =\begin{verbatim}= blocks are skipped.
The C =books/untanglec.c= carries the exact same reverse so the build
regenerates byte-identical .pamphlet (verified over all 1000 files).

#+BEGIN_SRC elisp
(defun pamphlet-roundtrip--prose-fwd (line)
  "Prose line: pamphlet -> org-native heading, or escape a leading-*/leading-- line."
  (cond
   ((string-match "\\`\\\\chapter{\\([^}]*\\)}\\'" line)       (concat "* "    (match-string 1 line)))
   ((string-match "\\`\\\\subsubsection{\\([^}]*\\)}\\'" line) (concat "**** " (match-string 1 line)))
   ((string-match "\\`\\\\subsection{\\([^}]*\\)}\\'" line)    (concat "*** "  (match-string 1 line)))
   ((string-match "\\`\\\\section{\\([^}]*\\)}\\'" line)       (concat "** "   (match-string 1 line)))
   ((string-match "\\`,*\\*" line) (concat "," line))
   ;; a literal "- X" prose line (e.g. a math-array row "- & - & ...") would be
   ;; read back as an org list item, so escape it like the *-case (phase 2)
   ((string-match "\\`,*- " line) (concat "," line))
   (t line)))

(defun pamphlet-roundtrip--prose-rev (line)
  "Prose line: org-native heading -> pamphlet, or unescape one leading comma."
  (cond
   ((string-match "\\`,*\\*" line)
    (if (eq (aref line 0) ?,)
        (substring line 1)
      (cond
       ((string-match "\\`\\*\\*\\*\\* \\(.*\\)\\'" line) (concat "\\subsubsection{" (match-string 1 line) "}"))
       ((string-match "\\`\\*\\*\\* \\(.*\\)\\'" line)    (concat "\\subsection{"    (match-string 1 line) "}"))
       ((string-match "\\`\\*\\* \\(.*\\)\\'" line)       (concat "\\section{"       (match-string 1 line) "}"))
       ((string-match "\\`\\* \\(.*\\)\\'" line)          (concat "\\chapter{"       (match-string 1 line) "}"))
       (t line))))
   ;; a comma-escaped "- X" line (non-comma "- X" is a real list item, handled
   ;; by the itemize reverse before this helper is ever reached)
   ((string-match "\\`,*- " line)
    (if (eq (aref line 0) ?,) (substring line 1) line))
   (t line)))
#+END_SRC

* Phase 3: org-native verbatim blocks (=#+begin_example=)

Phase 1/2 left =\begin{verbatim}..\end{verbatim}= prose blocks raw -- they were
the skip zone where headings and itemize escapes did not fire.  Phase 3 makes
the *clean* ones org-native: =\begin{verbatim}= <-> =#+begin_example=,
=\end{verbatim}= <-> =#+end_example=, with the block's content emitted verbatim
between them.  =org-latex-example-block= exports a =#+begin_example= as a
=verbatim= environment, so this is the inverse of org's own LaTeX backend.

Three rules keep it a byte bijection, so only *clean* blocks convert:

- *Both delimiters must trim exactly.*  =\begin{verbatim}= converts only when
  the line trims to exactly that token (leading/trailing whitespace is carried
  by =string-replace=); the block ends at the first line whose trim *ends with*
  =\end{verbatim}=, and converts only when that end trims to exactly the token.
  A block whose =\end= carries trailing content (=...))\end{verbatim}=), or a
  commented =%\begin{verbatim}=, or a =\verb|\begin{verbatim}|= mention, stays
  raw -- =#+end_example= must stand alone on its line, so those cannot convert.
- *No marker collision inside.*  A block whose content already holds a line
  trimming to =#+begin_example=/=#+end_example= stays raw (none exist in the
  corpus, but the guard keeps the reverse unambiguous).
- *Whitespace is preserved exactly*, so an indented =  \begin{verbatim}= round
  trips through =  #+begin_example=.

The forward lives in =pamphlet-roundtrip-to-org= (a look-ahead that scans to the
matching =\end=); the reverse in =pamphlet-roundtrip-to-pamphlet= and, for the
build, in =books/untanglec.c='s =#+begin_example= handling.  All three carry the
identical rule -- verified byte-exact over the corpus by =check-pamphlet-bytes=
(2232 blocks across 98 files) and by =to-pamphlet(to-org(P)) == P=.

* Forward: pamphlet -> org

#+BEGIN_SRC elisp
(defun pamphlet-roundtrip-to-org (text filename)
  "Convert pamphlet TEXT to reversible org.  FILENAME picks the src lang."
  ;; Keep ALL split fields (including the trailing "" from a final \n, and any
  ;; empty lines) and join without appending -- this preserves the exact
  ;; trailing-newline state, so a file with no final newline round-trips too.
  (let ((out '()) (in-chunk nil) (lines (split-string text "\n")))
    (while lines
      (let* ((line (pop lines)) (trimmed (string-trim line)))
        (cond
         (in-chunk
          (cond
           ;; \end{chunk}EXTRA at column 0 -- carry EXTRA (trailing space, a
           ;; malformed "p" or "{*}") on the #+end_src line so it reverses exactly
           ((string-prefix-p "\\end{chunk}" line)
            (push (concat pamphlet2org--src-prefix "end_src"
                          (substring line (length "\\end{chunk}")))
                  out)
            (setq in-chunk nil))
           ((string-match "\\`\\\\getchunk{\\([^}]*\\)}\\'" line)
            (push (format "<<%s>>" (match-string 1 line)) out))
           (t (push line out))))
         ;; a CLEAN \begin{verbatim}..\end{verbatim} block -- both delimiters trim
         ;; exactly, no #+begin_example/#+end_example line inside -- becomes an org
         ;; #+begin_example block (string-replace keeps the markers' surrounding
         ;; whitespace).  Messy blocks (\end with trailing content, etc.) stay raw,
         ;; exactly as before.  untanglec.c carries the identical rule.
         ((string= trimmed "\\begin{verbatim}")
          (let ((content '()) endline)
            (while (and lines (not (string-suffix-p "\\end{verbatim}"
                                                    (string-trim (car lines)))))
              (push (pop lines) content))
            (setq endline (car lines) content (nreverse content))
            (if (and endline
                     (string= (string-trim endline) "\\end{verbatim}")
                     (not (cl-some (lambda (c) (member (string-trim c)
                                                       '("#+begin_example" "#+end_example")))
                                   content)))
                (progn (pop lines)
                       (push (string-replace "\\begin{verbatim}" "#+begin_example" line) out)
                       (dolist (c content) (push c out))
                       (push (string-replace "\\end{verbatim}" "#+end_example" endline) out))
              (push line out)
              (dolist (c content) (push c out))
              (when endline (push (pop lines) out)))))
         ;; \begin{chunk}{NAME}EXTRA at column 0 -- NAME up to the first }, EXTRA
         ;; (e.g. a stray }) appended to #+begin_src for exact reversal
         ((string-match "\\`\\\\begin{chunk}{\\([^}]*\\)}\\(.*\\)\\'" line)
          (let ((name (match-string 1 line)) (extra (match-string 2 line)))
            (push (format "%sNAME: %s" pamphlet2org--src-prefix name) out)
            (push (format "%sbegin_src %s :noweb yes%s"
                          pamphlet2org--src-prefix
                          (pamphlet2org--detect-lang name filename) extra)
                  out)
            (setq in-chunk t)))
         ;; itemize block (prose): a CANONICAL \begin{itemize}..\end{itemize}
         ;; (every inner line a single-line `\item X', no blank/\item[/nesting)
         ;; becomes org `- X' lines; anything else stays verbatim.  The dropped
         ;; \begin/\item/\end are re-derived by the inverse (and untanglec.c).
         ((string= line "\\begin{itemize}")
          (let ((items '()) (block '()) (canonical t))
            (while (and lines (not (string= (car lines) "\\end{itemize}")))
              (let ((l (pop lines)))
                (push l block)
                (if (string-match "\\`\\\\item \\(.+\\)\\'" l)
                    (push (match-string 1 l) items)
                  (setq canonical nil))))
            (if (and lines (string= (car lines) "\\end{itemize}") canonical items)
                (progn (pop lines)
                       (dolist (it (nreverse items)) (push (concat "- " it) out)))
              (push "\\begin{itemize}" out)
              (dolist (l (nreverse block)) (push l out))
              (when (and lines (string= (car lines) "\\end{itemize}")) (push (pop lines) out)))))
         ;; getchunk/<<>> are only converted INSIDE chunks (where org-babel
         ;; noweb actually expands them).  In prose, both \getchunk{x} and a
         ;; literal <<x>> stay verbatim, so a literal <<x>> (e.g. bookvol11)
         ;; is never mistaken for a reference on the way back.  Prose headings
         ;; and leading-*/- escapes are handled by --prose-fwd.
         (t (push (pamphlet-roundtrip--prose-fwd line) out)))))
    (string-join (nreverse out) "\n")))
#+END_SRC

* Inverse: org -> pamphlet

#+BEGIN_SRC elisp
(defun pamphlet-roundtrip-to-pamphlet (text)
  "Reverse `pamphlet-roundtrip-to-org': org TEXT back to pamphlet."
  (let ((out '()) (lines (split-string text "\n")) (pfx pamphlet2org--src-prefix)
        (in-src nil) (in-verbatim nil) (in-example nil))
    (while lines
      (let* ((line (pop lines)) (trimmed (string-trim line)))
        (cond
         ;; #+begin_example (org-native form of a clean verbatim block) reverses
         ;; to \begin{verbatim}; content is raw; #+end_example closes it.  The
         ;; string-replace preserves the marker line's surrounding whitespace.
         (in-example
          (if (string= trimmed "#+end_example")
              (progn (push (string-replace "#+end_example" "\\end{verbatim}" line) out)
                     (setq in-example nil))
            (push line out)))
         ((and (not in-src) (string= trimmed "#+begin_example"))
          (push (string-replace "#+begin_example" "\\begin{verbatim}" line) out)
          (setq in-example t))
         ;; inside a prose \begin{verbatim} block leave every line raw -- a block
         ;; whose \end carried trailing content was left raw (not org-ified), so
         ;; the forward never rewrote headings there and we must not reverse them
         (in-verbatim
          (push line out)
          (when (string-suffix-p "\\end{verbatim}" trimmed) (setq in-verbatim nil)))
         ((and (not in-src) (string= trimmed "\\begin{verbatim}"))
          (push line out) (setq in-verbatim t))
         ((string-prefix-p (concat pfx "NAME: ") line)
          (let ((name (substring line (length (concat pfx "NAME: ")))))
            (if (and lines (string-prefix-p (concat pfx "begin_src ") (car lines)))
                (let* ((bs (pop lines))      ; #+begin_src LANG :noweb yesEXTRA
                       (extra (if (string-match ":noweb yes\\(.*\\)\\'" bs)
                                  (match-string 1 bs) "")))
                  (push (format "\\begin{chunk}{%s}%s" name extra) out)
                  (setq in-src t))
              (push (pamphlet-roundtrip--prose-rev line) out))))   ; lone #+NAME: prose
         ((and in-src (string-prefix-p (concat pfx "end_src") line))
          (push (concat "\\end{chunk}"
                        (substring line (length (concat pfx "end_src"))))
                out)
          (setq in-src nil))
         ;; <<x>> reverts to \getchunk{x} only inside a chunk (src block);
         ;; a literal <<x>> in prose stays as-is
         ((and in-src (string-match "\\`<<\\([^>]*\\)>>\\'" line))
          (push (format "\\getchunk{%s}" (match-string 1 line)) out))
         ;; a prose run of `- X' lines reverses to one \begin{itemize}.. block,
         ;; exactly re-inserting the scaffolding the forward dropped.  A literal
         ;; `- ' line was escaped to `,- ' by the forward, so it does not match.
         ((and (not in-src) (string-match "\\`- \\(.+\\)\\'" line))
          (let ((items (list (match-string 1 line))))
            (while (and lines (string-match "\\`- \\(.+\\)\\'" (car lines)))
              (push (match-string 1 (pop lines)) items))
            (push "\\begin{itemize}" out)
            (dolist (it (nreverse items)) (push (concat "\\item " it) out))
            (push "\\end{itemize}" out)))
         ;; chunk code raw; prose gets the heading reverse / comma-unescape
         (t (push (if in-src line (pamphlet-roundtrip--prose-rev line)) out)))))
    (string-join (nreverse out) "\n")))
#+END_SRC

* Round-trip test

#+BEGIN_SRC elisp
(defun pamphlet-roundtrip-test-file (pamphlet)
  "Return t if PAMPHLET survives pamphlet->org->pamphlet byte-for-byte."
  (let* ((orig (with-temp-buffer
                 (set-buffer-multibyte nil)
                 (insert-file-contents-literally pamphlet)
                 (buffer-string)))
         (org (pamphlet-roundtrip-to-org orig (file-name-nondirectory pamphlet)))
         (back (pamphlet-roundtrip-to-pamphlet org)))
    (string= orig back)))
#+END_SRC

* Corpus round-trip E2E

Walk every =.pamphlet= under ROOT and assert each survives the round trip
byte-for-byte.  This is the migration's go/no-go gate for losslessness:
if a file rebuilds exactly, the =.org= provably holds all of it (and the
rebuilt =.pamphlet= compiles to the identical PDF -- same input, same
output).  =AX=/path emacs --batch ... --eval '(pamphlet-roundtrip-test-all)'.

#+BEGIN_SRC elisp
(require 'cl-lib)
(require 'seq)

(defun pamphlet-roundtrip-test-all (&optional root)
  "Round-trip every .pamphlet under ROOT; report an OK/DIFFER tally.
Returns (:ok N :differ N :failures (RELPATH ...))."
  (let* ((root (or root (getenv "AX") default-directory))
         (files (seq-filter (lambda (x) (not (string-match-p "/\\.git/" x)))
                            (directory-files-recursively root "\\.pamphlet\\'")))
         (ok 0) (bad 0) (fails '()))
    (dolist (f files)
      (condition-case _
          (if (pamphlet-roundtrip-test-file f)
              (cl-incf ok)
            (cl-incf bad) (push (file-relative-name f root) fails))
        (error (cl-incf bad) (push (concat (file-name-nondirectory f) " (error)")
                                   fails))))
    (message "round-trip: %d OK / %d DIFFER (of %d)" ok bad (length files))
    (dolist (x (nreverse fails)) (message "  FAIL %s" x))
    (list :ok ok :differ bad :failures fails)))
#+END_SRC

* Build-path byte gate (=check-pamphlet-bytes.sh=)

=pamphlet-roundtrip-test-all= above proves the *elisp* converter is
reversible on the upstream pamphlets, in memory.  It does not exercise the
path the build actually takes: the C =books/untanglec.c= reading the
*migrated tracked =.org=*.  =tools/check-pamphlet-bytes.sh= closes that gap
and is the per-phase gate.

Its invariant is stronger and needs no allowlist: regenerate every tracked
source pamphlet twice -- once from a BASE ref with BASE's own =untanglec=,
once from the working tree with the current =untanglec= -- and assert the
two are byte-identical.  Because it compares *build output across a change*,
an intentional content edit living in =BASE..worktree= (an SBCL code patch,
a Makefile rewiring) is invisible to it; only a prose rewrite that actually
moved pamphlet bytes can make it fail.  That is exactly the property each
org-native phase must preserve.

Two traps the script encodes:

- *Tracked-only.*  It selects =git ls-files '*.org'=, not a working-tree
  =grep=, so git-ignored build artifacts that happen to carry =:noweb yes=
  (e.g. =src/interp/bookvol5.org=, regenerated during the build) never enter
  the gate and never raise a false regression.
- *No =mapfile=.*  The recipe runs under macOS =/bin/bash= 3.2, which
  predates =mapfile= (bash 4); the candidate list is streamed through a temp
  file instead.

Run it after each phase (BASE defaults to HEAD):

#+BEGIN_SRC sh
make check-pamphlet-bytes BASE=<pre-phase-ref>   # e.g. the commit before phase 1
# or directly:
tools/check-pamphlet-bytes.sh <pre-phase-ref>
#+END_SRC

Exit 0 means the rewrite was byte-transparent; exit 1 lists every pamphlet
whose bytes moved.

* Migration + build helpers

The migration makes =X.pamphlet.org= the source and treats =X.pamphlet=
as a regenerated build artifact.  =migrate-all= writes the org files once;
=regen-all= rebuilds the exact pamphlets from them at build time (so the
existing =tanglec= / =make= rules keep working byte-for-byte).

#+BEGIN_SRC elisp
(defun pamphlet-roundtrip-convert-file (pamphlet)
  "Write PAMPHLET's reversible org beside it as PAMPHLET\".org\"."
  (let ((orig (with-temp-buffer (set-buffer-multibyte nil)
                (insert-file-contents-literally pamphlet) (buffer-string)))
        (coding-system-for-write 'binary))
    (with-temp-file (concat pamphlet ".org")
      (insert (pamphlet-roundtrip-to-org orig (file-name-nondirectory pamphlet))))
    (concat pamphlet ".org")))

(defun pamphlet-roundtrip-regen-file (orgfile)
  "Rebuild the .pamphlet from ORGFILE (a *.pamphlet.org); return its path."
  (let ((pamphlet (string-remove-suffix ".org" orgfile))
        (org (with-temp-buffer (set-buffer-multibyte nil)
               (insert-file-contents-literally orgfile) (buffer-string)))
        (coding-system-for-write 'binary))
    (with-temp-file pamphlet
      (insert (pamphlet-roundtrip-to-pamphlet org)))
    pamphlet))

(defun pamphlet-roundtrip-migrate-all (&optional root)
  "Convert every .pamphlet under ROOT to a sibling .pamphlet.org."
  (let ((root (or root (getenv "AX") default-directory)) (n 0))
    (dolist (f (seq-filter (lambda (x) (not (string-match-p "/\\.git/" x)))
                           (directory-files-recursively root "\\.pamphlet\\'")))
      (pamphlet-roundtrip-convert-file f) (cl-incf n))
    (message "migrated %d pamphlets -> .pamphlet.org" n) n))

(defun pamphlet-roundtrip-regen-all (&optional root)
  "Rebuild every .pamphlet from its .pamphlet.org under ROOT (build step)."
  (let ((root (or root (getenv "AX") default-directory)) (n 0))
    (dolist (f (directory-files-recursively root "\\.pamphlet\\.org\\'"))
      (unless (string-match-p "/\\.git/" f)
        (pamphlet-roundtrip-regen-file f) (cl-incf n)))
    (message "regenerated %d pamphlets from .org" n) n))
#+END_SRC
