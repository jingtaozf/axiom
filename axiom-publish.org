# -*- mode: org; -*-
#+TITLE: axiom-publish -- headless org -> HTML publisher for the axiom tree
#+AUTHOR: Jingtao Xu
#+PROPERTY: literate-load yes
#+PROPERTY: literate-lang elisp
#+PROPERTY: header-args :results silent

* Why this exists

GitHub renders =.org= files through =github-markup= -> =org-ruby=, which
silently falls back to plain text above ~2 MB.  The axiom tree has dozens of
=.org= over that cap, topped by =books/bookvol10.5.org= at 31 MB / 56k
headings.  This tool publishes every tracked =.org= to a local browsable HTML
mirror with no size limit, using Emacs's own =ox-html= exporter -- the
reference org implementation -- run headlessly, one file per process so that
=make -j= can parallelise across the single-threaded Emacs.

This file is loaded literately (=literate-elisp-load=); =axiom-html.mk= calls
=axiom-publish-file= once per source file.

* Export settings

Every batch export of these files must override a handful of defaults, each
for a measured reason (numbers from Emacs 31 on this repo):

- =org-export-with-toc nil= -- a 56k-heading file would emit a 56k-entry
  table of contents; turning it off cut =bookvol10.2= export from 75.7s to
  5.9s (12.9x), the single biggest win.
- =org-export-with-broken-links 'mark= -- the default (=nil=) /aborts/ the
  whole export on the first dangling internal link; across 56k headings
  broken cross-refs are certain, so the default never finishes.
- =org-export-use-babel nil= -- never evaluate code on export; also drops
  per-block processing overhead.
- =large-file-warning-threshold nil= -- files over 9.5 MiB otherwise hang a
  =--batch= Emacs on an interactive y/n/l =find-file= prompt and abort on EOF.
- =org-export-with-section-numbers nil= -- skips a hierarchical counter for
  every one of 56k headings.
- =org-html-validation-link nil= -- drops a useless W3C-validator link from
  every page footer.
- =org-html-htmlize-output-type 'css= -- emits class names (one shared
  stylesheet) instead of inline faces, which do not exist in batch.  Needs
  =htmlize= >= 1.34 loaded to fontify; without it source blocks degrade to
  plain text (no error, just a warning).
- GC headroom -- a 31 MB / 56k-heading parse conses gigabytes of garbage.
  =gc-cons-threshold= 2 GB (=gc-cons-percentage= 0.6) removes GC thrash on
  ordinary book volumes; the monster needs 6 GB (set by =axiom-html.mk=).

The settings live as let-bindings inside =axiom-publish-file= so loading this
file mutates no global state, and the source buffer is killed after each
export so a long-running parent never accumulates buffers.

#+begin_src elisp
(require 'ox-html)
(require 'htmlize nil t)                 ; optional: enables source fontification

(defvar axiom-publish-gc-bytes (* 2 1024 1024 1024)
  "`gc-cons-threshold' to use during one export.
Raise for heading-dense monsters; `axiom-html.mk' sets 6 GB for
books/bookvol10.5.org (56k headings, ~9.6 min, ~1.5 GB measured).")

(defvar axiom-publish-gc-percentage 0.6
  "`gc-cons-percentage' during export -- fewer, larger GC cycles.")

(defun axiom-publish-file (src out)
  "Export org file SRC to HTML file OUT with batch-safe, heading-scale settings.
Writes to OUT directly (not beside SRC) so the caller owns the mirror layout.
Returns OUT."
  ;; Resolve both paths NOW, against the caller's cwd, before `find-file-noselect'
  ;; switches `default-directory' to SRC's own directory (which would misplace OUT).
  (setq src (expand-file-name src)
        out (expand-file-name out))
  (let ((gc-cons-threshold        axiom-publish-gc-bytes)
        (gc-cons-percentage       axiom-publish-gc-percentage)
        (large-file-warning-threshold nil)
        (org-export-use-babel     nil)
        (org-export-with-broken-links 'mark)
        (org-export-with-toc      nil)
        (org-export-with-section-numbers nil)
        (org-html-validation-link nil)
        (org-html-htmlize-output-type 'css)
        (max-lisp-eval-depth      100000)
        (coding-system-for-write  'utf-8)
        (t0 (current-time)))
    (make-directory (file-name-directory out) t)
    (let ((buf (find-file-noselect src)))
      (unwind-protect
          (with-current-buffer buf
            (let ((html (org-export-as 'html)))
              (with-temp-file out (insert html))))
        (kill-buffer buf)))
    (message "axiom-publish: %s -> %s (%.1fs)"
             src out (float-time (time-subtract (current-time) t0)))
    out))
#+end_src
