The call 
\begin{verbatim}
laplace(log(z),z,w)
\end{verbatim}
causes an infinite loop between lfintegrate and monomialIntegrate.

Waldek modified the code to fail and return unevaluated.

A more reasonable return value, not supported by Axiom, would be:
\begin{verbatim}
  -log(w)-gamma
  -------------
       w
\end{verbatim}
