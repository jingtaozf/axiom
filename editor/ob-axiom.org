* Overview

=ob-axiom= lets a reader evaluate Axiom code from an Org source block with
=C-c C-c= and have the answer returned as the LaTeX that Axiom itself emits,
so that =org-latex-preview= renders it as a typeset formula in the buffer.

The module exists to remove a manual loop. Today, to see an Axiom result as
a formula you run the REPL, type =)set output tex on=, copy the =$$...$$=
block, paste it into a LaTeX scratch buffer and preview it. =ob-axiom=
collapses that into one keystroke on a code block, and persists both the
code and its rendered result in the same Org document — a computational
notebook over a computer-algebra system.

*Invariant.* The backend never translates mathematics itself. Axiom's
=TexFormat= domain (OutputForm → LaTeX) is the single source of truth for how
a value becomes a formula; =ob-axiom= only switches Axiom into TeX output
mode, captures the emitted block, strips the step-number annotation, and
hands the LaTeX to Org. If a value renders wrong, the bug is upstream in
=TexFormat=, not in this Elisp.

*Two execution paths.* The default is *one-shot*: each block runs in a fresh
=AXIOMsys= process fed over stdin — simple and correct, but it pays Axiom's
startup cost per block and shares no state. A block that names a =:session=
instead evaluates in a *persistent =comint= session* whose variable
bindings, =)set= flags, and type environment survive across blocks — the
stateful-CAS shape FriCAS's =efricas= provides. One-shot stays the default;
sessions are opt-in. See =Process Backend: Sessions=.

*Graphics is a session capability.* A one-shot =draw= can only return a
viewport /object/: there is no live viewport manager behind a bare
=AXIOMsys=. A =:session= instead launches through the =axiom= wrapper
(=axiom -gr -ht -ihere=), which is =sman= — it starts the viewport manager
and HyperDoc as socket-connected helpers, so =draw= opens a real X11 window.
See [[#session-graphics][Graphics and HyperDoc]].

* Public API

The user-facing surface is a small set of Org header arguments plus the
standard =org-babel-execute:axiom= entry point Org calls on =C-c C-c=.

| Header arg   | Values              | Role                                                       |
|--------------+---------------------+------------------------------------------------------------|
| =:session=   | name                | Persistent session sharing state across blocks (opt-in; default one-shot) |
| =:results=   | =drawer=            | Recommended: wrap result in a drawer so re-execution *replaces* it; fragment still previews |
| =:show=      | =tex= / =2d= / =both= | Which Axiom output format to capture (default =tex=)         |
| =:type=      | =show= / =hide=     | Append Axiom's =Type:= line under the result (default hide) |

Use =:results drawer=. The returned =\[ ... \]= lands inside a =:results:= …
=:end:= drawer under =#+RESULTS:=. The drawer is a single Org element, so
re-executing the block *replaces* the previous result instead of appending a
new one — the failure mode =:results raw= has, since raw multi-line output
carries no end marker for Org to bound and remove. The =\[ ... \]= inside the
drawer is still an ordinary LaTeX fragment, so =org-latex-preview= (or the
=org-latex-preview-mode= live minor mode on newer Org) renders it as an image.

| Entry point                | Role                                              |
|----------------------------+---------------------------------------------------|
| =org-babel-execute:axiom=  | Org calls this to run a block; returns the result |
| =ob-axiom-render-result=   | Wrap captured Axiom LaTeX as a previewable fragment |
| =ob-axiom-clear-log=       | Erase one instance's verbose log (=*ob-axiom-log:<name>*=) |

*Caching and async — use Org's own machinery, no ob-axiom code.* Re-running
an unchanged block can reuse Org's built-in =:cache yes=, which hashes the
block and skips re-execution. One-shot blocks are also =ob-async=-compatible
(=:async=): the one-shot path is a self-contained =call-process=, so it runs
in an async subprocess without freezing Emacs. Session blocks cannot be
async — they need the live comint process in this Emacs — and should not be
cached if a later block depends on their side effects.

The preamble pulls in Org Babel and declares the customization group plus the
knobs a site is most likely to change: the bare =AXIOMsys= REPL (for one-shot)
and the =axiom= wrapper (for a graphics session), the optional =AXIOM= home
directory, whether sessions enable graphics, the preview scale, and whether to
auto-preview.

* The TeX Output Contract

This section is prose-only: it records the upstream behaviour the backend is
built on, so a future maintainer need not rediscover it from the Axiom
sources or by running the REPL.

With =)set output algebra off= and =)set output tex on=, Axiom prints each
result as TeX display math whose closing carries a right-hand step number:

#+begin_example
,$$
{2 \  {\sin
\left(
{{\sqrt {x}}}
\right)}}
-{2 \  {\sqrt {x}} \  {\cos
\left(
{{\sqrt {x}}}
\right)}}
\leqno(1)
,$$
                                       Type: Union(Expression(Integer),...)
#+end_example

The capture step therefore: (1) isolates the lines between a bare =$$= and
the next bare =$$=; (2) drops the =\leqno(N)= line; (3) re-wraps the math as
=\[ ... \]= for Org. The =Type:= line is captured separately and re-attached
only under =:type show=.

Two pieces of noise must be filtered. A freshly started =AXIOMsys= prints
=WARNING: redefining BOOT::|...|= lines (a side effect of the in-progress
GCL→SBCL migration, emitted the first time each algebra constructor loads),
and the REPL echoes =(N) -> = prompts. Both are removed before capture. The
=$$= blocks come over stdout, and the one-shot path routes stderr to the
[[#verbose-logging][verbose log]], so most warnings never reach capture; the line filter remains
for session transcripts, where the streams arrive merged.

* Runtime Resolution

Resolution finds the Axiom executable and the =AXIOM= home it needs. The
auto-detection deliberately mirrors the repository's build output
(=mnt/<platform>/bin/AXIOMsys=) so the backend works with no configuration
inside this tree, while =ob-axiom-axiom-home= / =ob-axiom-command= cover any
other install.

#+begin_src elisp
(defun ob-axiom--find-axiom-home (&optional start)
  "Walk up from START (or `default-directory') for mnt/*/bin/AXIOMsys.
Return the mnt/<platform> directory holding it, or nil."
  (let ((dir (expand-file-name (or start default-directory)))
        (steps 0) found)
    (while (and dir (not found) (< steps 10))
      (let ((hits (file-expand-wildcards
                   (expand-file-name "mnt/*/bin/AXIOMsys" dir))))
        (when hits
          (setq found (directory-file-name
                       (file-name-directory
                        (directory-file-name
                         (file-name-directory (car hits))))))))
      (let ((parent (file-name-directory (directory-file-name dir))))
        (setq dir (unless (equal parent dir) parent)))
      (setq steps (1+ steps)))
    found))

(defun ob-axiom--runtime ()
  "Return a plist describing how to launch Axiom.
Keys: :program (the bare AXIOMsys REPL, for one-shot), :axiom-program (the
`axiom' wrapper, for a graphics :session), :env, :home."
  (let* ((home (or ob-axiom-axiom-home
                   (ob-axiom--find-axiom-home
                    (and ob-axiom--this-file
                         (file-name-directory ob-axiom--this-file)))
                   (ob-axiom--find-axiom-home default-directory)))
         (home (and home (expand-file-name home)))
         (homed-bin (and home (expand-file-name "bin/AXIOMsys" home)))
         (homed-axiom (and home (expand-file-name "bin/axiom" home)))
         (program (if (and homed-bin (file-executable-p homed-bin))
                      homed-bin
                    ob-axiom-command))
         (axiom-program (if (and homed-axiom (file-executable-p homed-axiom))
                            homed-axiom
                          ob-axiom-axiom-command))
         (env (if home
                  (cons (concat "AXIOM=" home) process-environment)
                process-environment)))
    (list :program program :axiom-program axiom-program
          :env env :home home)))

(defun ob-axiom--runtime-available-p ()
  "Non-nil when an Axiom executable can be located."
  (let ((p (plist-get (ignore-errors (ob-axiom--runtime)) :program)))
    (and p (or (file-executable-p p) (executable-find p)))))
#+end_src

* Verbose Logging
:PROPERTIES:
:CUSTOM_ID: verbose-logging
:END:

Every evaluation appends its full raw transcript to a per-instance log
buffer =*ob-axiom-log:<instance>*= — the =:session= name for session
blocks, =one-shot= for the fresh-process path (whose processes are
throwaway; a buffer per run would litter Emacs with dead logs). The
capture layer strips banners, prompts, and migration warnings before Org
sees a result, which is right for the document and wrong for debugging:
when a block misbehaves, the stripped lines are exactly the evidence.
The log keeps them.

Logging is unconditional and unbounded — no toggle, no size cap. During
the GCL→SBCL migration a truncated transcript is worse than none, so the
bound is manual: =M-x ob-axiom-clear-log= erases one instance's log. A
deliberate exception to the append-and-trim pattern used elsewhere in
this repo's tooling.

The log is also the only place a timed-out session's transcript
survives: the abort path kills the comint buffer to avoid a
desynchronised REPL, which used to destroy the evidence with it.

stderr handling differs by path, because separation must happen at the
process API — once merged, the streams cannot be split after the fact:

- *one-shot* — true separation: =call-process-region='s BUFFER argument
  takes the list form =(t err-file)=, landing stderr in a temp file that
  is logged under a =---- stderr ----= marker in
  =ob-axiom-log-stderr-face=.
- *session* — inseparable: a graphics session is a pty, where the merge
  happens at the file-descriptor level; a pipe session goes through
  comint, which exposes no =:stderr=. Lines matching known diagnostic
  shapes (=WARNING:=, =STYLE-WARNING=, semicolon-prefixed compiler
  notes, =>>= error banners) are heuristically highlighted with the same
  face — a best guess, not fd-level truth.

To find stderr: search =^---- stderr= (one-shot, exact) or scan for the
red =ob-axiom-log-stderr-face= (session, heuristic).

#+begin_src elisp
(defface ob-axiom-log-header-face
  '((t :inherit font-lock-comment-face :weight bold))
  "Face for entry headers and the stderr marker in ob-axiom log buffers.")

(defface ob-axiom-log-stderr-face
  '((t :inherit font-lock-warning-face))
  "Face for stderr (and stderr-shaped) lines in ob-axiom log buffers.")

(defconst ob-axiom--log-stderr-line-re
  "^\\(?:WARNING\\|STYLE-WARNING\\|;;? \\|>> \\).*"
  "Diagnostic-shaped lines heuristically highlighted in merged transcripts.")

(defun ob-axiom--log-buffer (instance)
  "Return, creating if needed, the log buffer for INSTANCE."
  (get-buffer-create (format "*ob-axiom-log:%s*" instance)))

(defun ob-axiom--log (instance label raw &optional stderr)
  "Append RAW to INSTANCE's log buffer under a LABEL header line.
When STDERR is a non-blank string (one-shot separation), append it under
a =---- stderr ----= marker in `ob-axiom-log-stderr-face'; independently,
highlight diagnostic-shaped lines inside RAW per
`ob-axiom--log-stderr-line-re'."
  (with-current-buffer (ob-axiom--log-buffer instance)
    (goto-char (point-max))
    (insert (propertize (format "==== [%s] %s\n"
                                (format-time-string "%F %T") label)
                        'face 'ob-axiom-log-header-face))
    (let ((beg (point)))
      (insert raw)
      (unless (bolp) (insert "\n"))
      (save-excursion
        (goto-char beg)
        (while (re-search-forward ob-axiom--log-stderr-line-re nil t)
          (put-text-property (match-beginning 0) (match-end 0)
                             'face 'ob-axiom-log-stderr-face))))
    (when (and stderr (not (string-blank-p stderr)))
      (insert (propertize "---- stderr ----\n" 'face 'ob-axiom-log-header-face)
              (propertize stderr 'face 'ob-axiom-log-stderr-face))
      (unless (bolp) (insert "\n")))))

(defun ob-axiom-clear-log (instance)
  "Erase the verbose log buffer for INSTANCE."
  (interactive
   (list (completing-read
          "Clear Axiom log: "
          (delq nil (mapcar
                     (lambda (b)
                       (and (string-match "\\`\\*ob-axiom-log:\\(.*\\)\\*\\'"
                                          (buffer-name b))
                            (match-string 1 (buffer-name b))))
                     (buffer-list)))
          nil t)))
  (let ((buf (get-buffer (format "*ob-axiom-log:%s*" instance))))
    (when buf (with-current-buffer buf (erase-buffer)))))
#+end_src

* One-Shot Evaluation

One-shot evaluation builds an input script — a format prelude, the user's
body, then =)quit= — and feeds it to a throwaway process via
=call-process-region=, returning the raw stdout. stderr is captured to a
temp file and routed to the [[#verbose-logging][verbose log]]. The list-form BUFFER argument
=(t err-file)= is what separates the streams — a plain =t= *mixes* stderr
into stdout (discarding needs =(t nil)=), which is why migration warnings
used to reach the capture filters at all.

#+begin_src elisp
(defun ob-axiom--prelude (show)
  "Return the )set output lines selecting the format for SHOW."
  (cond
   ((equal show "2d")   ")set output algebra on\n)set output tex off\n")
   ((equal show "both") ")set output algebra on\n)set output tex on\n")
   (t                   ")set output algebra off\n)set output tex on\n")))

(defun ob-axiom--eval-one-shot (body show)
  "Run BODY in a fresh Axiom process under format SHOW; return raw stdout.
stderr goes to a temp file and from there to the one-shot verbose log."
  (let* ((rt (ob-axiom--runtime))
         (program (plist-get rt :program))
         (process-environment (plist-get rt :env))
         (script (concat (ob-axiom--prelude show) body "\n)quit\n"))
         (err-file (make-temp-file "ob-axiom-stderr-")))
    (unless (or (file-executable-p program) (executable-find program))
      (error "ob-axiom: no Axiom executable (%s); set `ob-axiom-axiom-home'"
             program))
    (unwind-protect
        (with-temp-buffer
          (insert script)
          (call-process-region (point-min) (point-max) program t
                               (list t err-file) nil "--noinform")
          (let ((raw (buffer-string))
                (err (with-temp-buffer
                       (insert-file-contents err-file)
                       (buffer-string))))
            (ob-axiom--log "one-shot" (car (split-string body "\n")) raw err)
            raw))
      (delete-file err-file))))
#+end_src

* Output Capture

Capture turns the raw REPL transcript into the pieces Org needs: the LaTeX
math blocks, the type line, and — for the =2d= path or for errors — a cleaned
plain-text rendering. =ob-axiom--capture-tex= returns a list so a block that
prints several results renders each one.

#+begin_src elisp
(defconst ob-axiom--noise-re
  "^\\(WARNING: redefining\\|STYLE-WARNING\\|; \\|;; \\)"
  "Lines of compiler/migration noise dropped before capture.")

(defun ob-axiom--strip-noise (raw)
  "Return RAW's lines with compiler/migration noise removed."
  (seq-remove (lambda (l) (string-match-p ob-axiom--noise-re l))
              (split-string raw "\n")))

(defun ob-axiom--capture-tex (raw)
  "Return the list of LaTeX math strings emitted in RAW, \\leqno removed."
  (let ((blocks '()) (cur '()) (in nil))
    (dolist (l (ob-axiom--strip-noise raw))
      (if (string-match-p "^[ \t]*\\$\\$[ \t]*$" l)
          (if in
              (progn
                (push (string-trim (mapconcat #'identity (nreverse cur) "\n"))
                      blocks)
                (setq cur '() in nil))
            (setq in t cur '()))
        (when (and in (not (string-match-p "^[ \t]*\\\\leqno" l)))
          (push l cur))))
    (nreverse blocks)))

(defun ob-axiom--capture-type (raw)
  "Return the last Axiom Type: line in RAW, or nil."
  (let (type)
    (dolist (l (split-string raw "\n"))
      (when (string-match "^[ \t]*Type:[ \t]*\\(.*[^ \t]\\)[ \t]*$" l)
        (setq type (match-string 1 l))))
    type))

(defun ob-axiom--result-text (raw)
  "Return RAW reduced to its meaningful lines (banner/prompts/noise gone).
Used for the 2d format and to surface Axiom errors verbatim."
  (string-trim
   (mapconcat
    #'identity
    (seq-remove
     (lambda (l)
       (or (string-match-p ob-axiom--noise-re l)
           (string-match-p
            "AXIOM Computer Algebra System\\|Version: Axiom\\|Timestamp:\\|Issue )\\|Visit http\\|^-\\{5,\\}$"
            l)
           (string-match-p "^[ \t]*$" l)
           ;; One or more prompts on one line: a )set wrap echoes the prompt
           ;; without advancing N, so a session line can read "(3) -> (3) -> ".
           (string-match-p "^[ \t]*\\(([0-9]+)[ \t]*->[ \t]*\\)+$" l)))
     (split-string raw "\n"))
    "\n")))
#+end_src

* Result Rendering

Rendering wraps each captured math block as a display fragment and lets Org's
own preview machinery rasterize it, so results match the document's other
previews. The =:scale= is pushed into =org-format-latex-options= once.

#+begin_src elisp
(setq org-format-latex-options
      (plist-put (copy-sequence org-format-latex-options)
                 :scale ob-axiom-latex-scale))

(defun ob-axiom-render-result (tex-list &optional type)
  "Wrap each math string in TEX-LIST as a \\[ ... \\] fragment.
Append a Type line when TYPE is non-nil."
  (let ((body (mapconcat (lambda (m) (concat "\\[\n" m "\n\\]")) tex-list "\n")))
    (if type (concat body "\nType: " type) body)))
#+end_src

* Entry Point: org-babel-execute:axiom

Org calls this on =C-c C-c=. It runs the body, and — unless =:show 2d= asked
for ASCII art — captures the TeX and renders it. When no TeX is found (an
Axiom error, or output that produced no value) it returns the cleaned text so
the error is visible in the buffer rather than swallowed.

#+begin_src elisp
(defun org-babel-execute:axiom (body params)
  "Execute a block of Axiom BODY with org-babel using PARAMS."
  (let* ((show (or (cdr (assq :show params)) "tex"))
         (type-p (equal (cdr (assq :type params)) "show"))
         (session (let ((s (cdr (assq :session params))))
                    (if (member s '(nil "none" "no" "")) ob-axiom-default-session s)))
         (raw (if session
                  (ob-axiom--session-eval (ob-axiom--session-buffer session) body show)
                (ob-axiom--eval-one-shot body show))))
    (if (equal show "2d")
        (ob-axiom--result-text raw)
      (let ((tex (ob-axiom--capture-tex raw)))
        (if tex
            (ob-axiom-render-result
             tex (and type-p (ob-axiom--capture-type raw)))
          (ob-axiom--result-text raw))))))
#+end_src

* Automatic Preview

After execution, an =org-babel-after-execute-hook= previews the result of an
=axiom= block. This is best-effort and version-tolerant; the supported, more
robust path is Org's own automatic preview — =org-startup-with-latex-preview=
on classic Org, or the =org-latex-preview-mode= live minor mode on newer Org.

#+begin_src elisp
(defun ob-axiom--preview-region (beg end)
  "Best-effort preview of the LaTeX fragment between BEG and END."
  (ignore-errors
    (save-excursion
      (goto-char beg)
      (when (re-search-forward "\\\\\\[" end t)
        (cond
         ((fboundp 'org-latex-preview) (org-latex-preview))
         ((fboundp 'org-toggle-latex-fragment) (org-toggle-latex-fragment)))))))

(defun ob-axiom--preview-after-execute ()
  "Preview an axiom block's result when `ob-axiom-auto-preview' is on."
  (when (and ob-axiom-auto-preview (derived-mode-p 'org-mode))
    (let ((info (ignore-errors (org-babel-get-src-block-info t))))
      (when (and (consp info) (equal (nth 0 info) "axiom"))
        (let ((res (ignore-errors (org-babel-where-is-src-block-result))))
          (when res
            (save-excursion
              (goto-char res)
              (let ((beg (line-beginning-position 2))
                    (end (ignore-errors (org-babel-result-end))))
                (when (and beg end (< beg end))
                  (ob-axiom--preview-region beg end))))))))))

(add-hook 'org-babel-after-execute-hook #'ob-axiom--preview-after-execute)
#+end_src

* Editing Mode: axiom-mode
:PROPERTIES:
:CUSTOM_ID: axiom-mode
:END:

=axiom-mode= is a light major mode for Axiom / SPAD source — used for
=.input= and =.spad= files and as the =C-c '= edit buffer for =axiom= src
blocks. It ports the /stable/ syntax from the repository's =axiom.vim=:
language keywords, operators, =)= system commands, =%= macros, =-- / ++=
comments, and strings. It deliberately does /not/ embed axiom.vim's
auto-generated domain/operation/category/package tables (~5700 entries,
bound to a library version); a capitalized-identifier heuristic highlights
those as types instead, staying correct as the library evolves.

Comments are fontified by keyword (not by syntax table) so that =--= and
=++= each get their own face and never fire inside a string — the string is
already fontified syntactically, and a non-overriding keyword leaves it
alone.

#+begin_src elisp
(defvar axiom-mode-syntax-table

* Jump to Definition
:PROPERTIES:
:CUSTOM_ID: goto-definition
:END:

No system in the Axiom family offers symbol-level source navigation.
What they all track — verified in daly (=GETDATABASE ctor 'SOURCEFILE=,
bookvol5), FriCAS (=gdata.boot=, resolves into =src/algebra/=), and
OpenAxiom (=database.boot=) — is one fact per constructor: the file it
was compiled from. =)edit= hands that bare file to =$EDITOR= via the
SPADEDIT script; no line, no operations.

=axiom-goto-definition= (bound to =M-.= in =axiom-mode=) does better by
splitting the work between the live image and Emacs:

- The *image* answers the semantic question over the sly connection:
  a constructor name or abbreviation resolves through the daase to
  =(full-name abbreviation source-file)=; an operation name resolves
  through =getAllModemapsFromDatabase= to the constructors implementing
  it (offered via =completing-read=, then treated as a constructor).
  A daase modemap is =((dc target args...) pred)= where =dc= is a
  pattern variable (=*1=), so the implementing constructor is *not*
  the head of the signature — it must be dug out of the predicate's
  =(|isDomain| *1 (|Ctor| ...))= clause.  Both image-side forms are
  wrapped in =handler-case=: an error escaping a slynk request opens
  the sly debugger and blocks the synchronous =sly-eval= indefinitely.
- *Emacs* supplies the line-level precision the daase lacks: the file
  is located (buffer directory first, then =books/= derived from the
  image's own =$AXIOM=), and point lands on the
  =\begin{chunk}{domain ABBREV Name}= header (pamphlets) or the
  =)abbrev= line (plain =.spad=). An operation jump continues forward
  from that header to the implementation line in the capsule. The
  pattern =^[ \t]*op[ \t(:].*=== is what keeps this precise without an
  index: the SIG signature line (=op : (…) -> …=) carries no ====, and
  =++= doc lines never start with the bare operation name, so neither
  false-matches; if the line is not found, point stays at the header.

The daase is the build's source of truth, so this never needs an index
rebuild and works for user domains the moment they are =)co='d.
Requires a sly connection to the running AXIOMsys; without one the
command aborts with a clear message rather than guessing. The liveness
check is =sly-current-connection=, not =sly-connected-p=: when the
image dies (=connection broken by remote peer=) a stale entry can
linger in =sly-net-processes=, making =sly-connected-p= answer t while
every =sly-eval= fails — which used to surface as a misleading "not in
the daase" instead of "no connection".  =M-,= pops
back (the jump pushes the xref marker stack).  Evil users: =M-.= works
in normal state, or add a thin wrapper to
=evil-goto-definition-functions= in personal config.

#+begin_src elisp
(defun axiom--symbol-at-point ()
  "Symbol at point, Axiom-style: letters, digits, ! ? _ %."
  (save-excursion
    (let* ((chars "A-Za-z0-9!?_%")
           (beg (progn (skip-chars-backward chars) (point)))
           (end (progn (skip-chars-forward chars) (point))))
      (unless (= beg end) (buffer-substring-no-properties beg end)))))

(defun axiom--sly-connection-live-p ()
  "Non-nil when sly has a usable default connection, not a stale process."
  (and (fboundp 'sly-current-connection)
       (ignore-errors (sly-current-connection))))

(defun axiom--sly-eval-output (expr)
  "Eval EXPR (Lisp source string) in the image, package BOOT.
Return what it princs to standard output; nil when offline, on error,
or when nothing was printed."
  (when (axiom--sly-connection-live-p)
    (let ((res (ignore-errors
                 (sly-eval `(slynk:eval-and-grab-output ,expr) "BOOT"))))
      (when (and (consp res) (stringp (car res)) (> (length (car res)) 0))
        (car res)))))

(defun axiom--constructor-location (name)
  "Resolve NAME (constructor name or abbreviation) via the daase.
Return (FULL-NAME ABBREV FILE) as strings, or nil."
  (let ((out (axiom--sly-eval-output
              (format "(handler-case
                         (let* ((s (intern %S \"BOOT\"))
                                (c (or (getdatabase s 'constructor) s))
                                (f (getdatabase c 'sourcefile))
                                (a (getdatabase c 'abbreviation)))
                           (when f (princ (format nil \"~a ~a ~a\" c a f))))
                         (error (c) nil))"
                      name))))
    (when out (split-string out))))

(defun axiom--operation-constructors (op)
  "Constructors implementing operation OP, per the daase modemaps."
  (let ((out (axiom--sly-eval-output
              (format "(handler-case
                         (let (seen)
                           (dolist (mm (|getAllModemapsFromDatabase|
                                        (intern %S \"BOOT\") nil))
                             (let ((dc (caar mm)) (pred (cadr mm)))
                               (labels ((scan (p)
                                          (cond ((atom p) nil)
                                                ((and (eq (car p) '|isDomain|)
                                                      (eq (cadr p) dc)
                                                      (consp (caddr p)))
                                                 (car (caddr p)))
                                                (t (some #'scan p)))))
                                 (let ((c (scan pred)))
                                   (when (and c (not (member c seen)))
                                     (push c seen)
                                     (princ (format nil \"~a \" c))))))))
                         (error (c) nil))"
                      op))))
    (when out (split-string out))))

(defun axiom--resolve-source (file)
  "Find FILE from the daase on disk; nil when it cannot be located."
  (if (file-name-absolute-p file)
      (and (file-exists-p file) file)
    (let* ((axiom-home
            (axiom--sly-eval-output
             "(let ((h (sb-ext:posix-getenv \"AXIOM\"))) (when h (princ h)))"))
           (books (and axiom-home
                       (expand-file-name "../../books/" axiom-home))))
      (seq-some (lambda (dir)
                  (and dir
                       (let ((p (expand-file-name file dir)))
                         (and (file-exists-p p) p))))
                (list default-directory books)))))

(defun axiom--locate-definition (full abbrev file &optional op)
  "Visit FILE and land on the definition header of FULL/ABBREV.
When OP is non-nil, continue forward from the header to OP's
implementation line in the capsule (`op(...) =='); when that line is
not found, point stays at the header."
  (let ((path (axiom--resolve-source file)))
    (unless path (user-error "Cannot find %s locally" file))
    (xref-push-marker-stack)
    (find-file path)
    (goto-char (point-min))
    (let ((case-fold-search nil))
      (if (re-search-forward
           (format "^\\\\begin{chunk}{\\(?:domain\\|category\\|package\\) %s %s}\\|^)abbrev +\\(?:domain\\|category\\|package\\) +%s +%s\\_>"
                   (regexp-quote abbrev) (regexp-quote full)
                   (regexp-quote abbrev) (regexp-quote full))
           nil t)
          (beginning-of-line)
        (message "Header not found; at top of %s"
                 (file-name-nondirectory path)))
      (when op
        (if (re-search-forward
             (format "^[ \t]*%s[ \t(:].*==" (regexp-quote op)) nil t)
            (beginning-of-line)
          (message "%s: implementation line not found; at header" op))))))

(defun axiom-goto-definition (&optional name)
  "Jump to the definition of the Axiom symbol at point.
Constructor names and abbreviations resolve directly; operation names
offer their implementing constructors."
  (interactive)
  (let ((name (or name (axiom--symbol-at-point))))
    (unless name (user-error "No symbol at point"))
    (unless (axiom--sly-connection-live-p)
      (user-error "No live sly connection to a running Axiom (start one, then )read slynk)"))
    (let ((loc (axiom--constructor-location name)))
      (if loc
          (apply #'axiom--locate-definition loc)
        (let ((ctors (axiom--operation-constructors name)))
          (unless ctors
            (user-error "No constructor or operation %s in the daase" name))
          (let ((cloc (axiom--constructor-location
                       (completing-read (format "%s implemented in: " name)
                                        ctors nil t))))
            (unless cloc (user-error "Constructor lost from the daase"))
            (apply #'axiom--locate-definition
                   (append cloc (list name)))))))))

(define-key axiom-mode-map (kbd "M-.") #'axiom-goto-definition)
(define-key axiom-mode-map [remap xref-find-definitions] #'axiom-goto-definition)
#+end_src

* Process Backend: Sessions
:PROPERTIES:
:CUSTOM_ID: sessions
:END:

A persistent =comint= session keyed by =:session= lets variable bindings,
=)set= flags, and the inferred type environment survive across blocks — the
stateful-CAS shape FriCAS's =efricas= provides. Sessions are opt-in; one-shot
stays the default.

** Graphics and HyperDoc via the sman wrapper
:PROPERTIES:
:CUSTOM_ID: session-graphics
:END:

A bare =AXIOMsys= cannot draw: the X11 window is produced by =viewman= (the
viewport manager, =ViewportServer= socket index 2), which =draw= reaches over
a socket but which nothing starts on its own. =sman= — Axiom's session
manager, invoked through the =axiom= wrapper — is what wires this up.
=axiom -gr -ht -ihere= expands to =sman -gr -ht -ihere -ws AXIOMsys=: =sman=
injects =SPADSERVER=/=SPADNUM= so the interpreter opens its server sockets,
forks =viewman= (=-gr=) and =hypertex= (=-ht=) as clients, and keeps the
interpreter in /this/ comint terminal (=-ihere=) rather than a separate xterm.
A graphics =:session= is therefore the same process tree the interactive
=axiom= command builds — the one already proven to pop a viewport.

Three consequences shape the backend:

- *A pty, not a pipe.* =sman= and the helpers expect a controlling tty
  (=-ihere= does =isatty=/termios setup), so a graphics session binds
  =process-connection-type= to t. The bare-REPL session keeps its pipe for
  clean line-buffered I/O.
- *=-noclef=.* The default Clef line-editor paints terminal escape sequences
  that would corrupt the captured transcript; comint already provides line
  editing, so the launch drops it.
- *=DISPLAY= is inherited.* =viewman= opens the window against whatever
  =DISPLAY= Emacs carries (the XQuartz display on macOS) — no injection, the
  subprocess inherits the parent environment.

Set =ob-axiom-session-graphics= to nil to fall back to the bare =AXIOMsys=
session on a host with no X server.

** Knowing when a command has finished

The hard part of any REPL backend is detecting completion. Axiom's prompt
=(N) -> = increments its number on each input, so after sending a block we
wait for an idle prompt whose number /exceeds/ the one present before the
send. Matching the bare prompt /text/ alone would race: right after sending,
the previous idle prompt is still the last line until Axiom starts
responding, so a text-only match returns immediately with empty output. The
number guard closes that race.

One wrinkle: =)set= and other system commands do /not/ increment =N=, so the
prelude that primes TeX output cannot be gated by a number increment — it is
fired and ordered, then the first real computation's numbered wait gates the
result.

A block may hold several statements, so the wait /target/ is the baseline
number plus the count of statements (continuation lines joined; blank,
comment, and =)command= lines excluded). Because an erroring statement does
not always advance =N=, the wait also completes when output has been quiet
for a short interval at a prompt — the fallback that keeps errors from
hanging to the timeout. If even that fails (a genuine hang), the eval
abandons the session and surfaces an error rather than leaving it
desynchronised.

#+begin_src elisp
(defvar ob-axiom--sessions (make-hash-table :test 'equal)
  "Map of :session name -> live comint buffer. Reaped when its process exits.")

(defconst ob-axiom--prompt-re "(\\([0-9]+\\)) +-> *\\'"
  "Axiom's idle prompt anchored at end of buffer; group 1 is the number N.")

(defun ob-axiom--last-prompt-number (buffer)
  "Return N of the last (N) -> prompt in BUFFER, or nil."
  (with-current-buffer buffer
    (save-excursion
      (goto-char (point-max))
      (and (re-search-backward "^(\\([0-9]+\\)) +-> " nil t)
           (string-to-number (match-string 1))))))

(defun ob-axiom--session-wait (proc &optional timeout target quiet)
  "Block until PROC's buffer settles at an idle Axiom prompt.
Completion = the last line is a prompt AND either its number reaches
TARGET, or output has been quiet for QUIET seconds — the fallback that
catches errors, which do not always advance the number.  The deadline is
checked before the prompt, so a tiny TIMEOUT aborts deterministically.
Return the prompt number, or `timeout', or `dead'."
  (let* ((deadline (+ (float-time) (or timeout ob-axiom-session-timeout)))
         (quiet (or quiet 0.3))
         (buf (process-buffer proc))
         (last-size (buffer-size buf))
         (last-change (float-time))
         result)
    (while (not result)
      (accept-process-output proc 0.05)
      (let ((sz (buffer-size buf)))
        (unless (= sz last-size) (setq last-size sz last-change (float-time))))
      (cond
       ((not (process-live-p proc)) (setq result 'dead))
       ((> (float-time) deadline) (setq result 'timeout))
       (t ;; Match the prompt at the very END of the buffer.  A )set
          ;; command re-echoes the prompt at the current number, so the
          ;; last line can read "(2) -> (2) -> (2) -> "; a tail string-match
          ;; anchored at \\=\\' picks the final one, where a line-start
          ;; `looking-at' would fail on the concatenation.
        (let ((tail (with-current-buffer buf
                      (buffer-substring-no-properties
                       (max (point-min) (- (point-max) 80)) (point-max)))))
          (when (string-match ob-axiom--prompt-re tail)
            (let ((n (string-to-number (match-string 1 tail))))
              (when (or (and target (>= n target))
                        (>= (- (float-time) last-change) quiet))
                (setq result n))))))))
    result))
#+end_src

** Session lifecycle

A session is a comint process whose connection type depends on
=ob-axiom-session-graphics=: a graphics session runs the =axiom= wrapper over a
*pty* (=process-connection-type= t) because sman + the viewport helpers want a
controlling tty, while a non-graphics session keeps the bare REPL on a *pipe*
(=process-connection-type nil=) for clean line-buffered I/O — see [[#session-graphics][Graphics and HyperDoc]]. The TeX format is
primed once at start, not per block. Lifecycle is bounded per the project's
resource rule: a sentinel reaps the hash entry on process death, and a
buffer-local =kill-buffer-hook= forgets a killed session. Both closures use
=apply-partially= rather than a =lambda= because literate-elisp loads under
dynamic binding, where a lambda would not capture the session key.

#+begin_src elisp
(defun ob-axiom--session-sentinel (session proc _event)
  "Forget SESSION when its PROC dies."
  (unless (process-live-p proc)
    (remhash session ob-axiom--sessions)))

(defun ob-axiom--session-start (session)
  "Start, prime for TeX, and return a fresh comint buffer for SESSION.
With `ob-axiom-session-graphics' on, launch the `axiom' wrapper (sman)
under a pty so `draw' opens an X11 viewport and HyperDoc is reachable;
otherwise launch the bare `AXIOMsys' REPL over a pipe (no window)."
  (let* ((rt (ob-axiom--runtime))
         (graphics ob-axiom-session-graphics)
         (program (plist-get rt (if graphics :axiom-program :program)))
         (args (if graphics ob-axiom-session-graphics-args '("--noinform")))
         (process-environment (plist-get rt :env))
         ;; A graphics session is sman + helpers, which want a controlling
         ;; tty (-ihere does isatty/termios); the bare REPL keeps the pipe.
         (process-connection-type graphics))
    (unless (or (file-executable-p program) (executable-find program))
      (error "ob-axiom: no Axiom executable (%s); set `ob-axiom-axiom-home'"
             program))
    (let* ((buf (apply #'make-comint-in-buffer
                       (format "ob-axiom:%s" session)
                       (format "*ob-axiom:%s*" session)
                       program nil args))
           (proc (get-buffer-process buf)))
      (set-process-query-on-exit-flag proc nil)
      (set-process-sentinel
       proc (apply-partially #'ob-axiom--session-sentinel session))
      (with-current-buffer buf
        (setq-local comint-prompt-regexp "^([0-9]+) +-> *")
        (add-hook 'kill-buffer-hook
                  (apply-partially #'remhash session ob-axiom--sessions)
                  nil t))
      (ob-axiom--session-wait proc ob-axiom-session-start-timeout)
      ;; )set system commands do NOT bump the (N) step number, so they
      ;; cannot be gated by a number increment.  Axiom reads stdin in
      ;; order, so fire the format prelude and let the first real eval's
      ;; numbered wait gate everything that follows.
      (process-send-string proc ")set output algebra off\n)set output tex on\n")
      (accept-process-output proc 0.1)
      buf)))

(defun ob-axiom--session-buffer (session)
  "Return a live, TeX-primed comint buffer for SESSION, creating it if needed."
  (let ((buf (gethash session ob-axiom--sessions)))
    (unless (and (buffer-live-p buf)
                 (process-live-p (get-buffer-process buf)))
      (setq buf (ob-axiom--session-start session))
      (puthash session buf ob-axiom--sessions))
    buf))
#+end_src

** Evaluating in a session

Evaluation records the prompt number and buffer end before sending, then
returns the transcript that appeared after the send — which the same capture
helpers as the one-shot path turn into LaTeX. The slice is also appended to
the session's [[#verbose-logging][verbose log]]; on timeout the log write happens *before* the
comint buffer is killed, so the partial transcript survives the abort.

#+begin_src elisp
(defun ob-axiom--count-statements (body)
  "Count Axiom statements in BODY.
Continuation lines (ending in _) are joined; blank, comment (-- / ++),
and )system-command lines are not counted, as they do not advance the
(N) step number."
  (let ((lines (split-string
                (replace-regexp-in-string "_[ \t]*\n" " " body) "\n")))
    (length (seq-remove
             (lambda (l) (let ((s (string-trim l)))
                           (or (string-empty-p s)
                               (string-prefix-p "--" s)
                               (string-prefix-p "++" s)
                               (string-prefix-p ")" s))))
             lines))))

(defun ob-axiom--wrap-show (body show)
  "Wrap BODY with the )set commands selecting SHOW, restoring TeX afterwards.
The session rests at tex-on / algebra-off; a 2d or both block toggles for
its own duration then restores, so later blocks stay on TeX."
  (cond
   ((equal show "2d")
    (concat ")set output tex off\n)set output algebra on\n"
            body "\n)set output algebra off\n)set output tex on\n"))
   ((equal show "both")
    (concat ")set output algebra on\n" body "\n)set output algebra off\n"))
   (t (concat body "\n"))))

(defun ob-axiom--session-eval (buffer body show)
  "Send BODY (under format SHOW) to session BUFFER; return its raw transcript.
On timeout the session is abandoned (killed) and an error string returned,
rather than leaving a desynchronised process behind; the partial
transcript is logged first — the log is its only surviving copy."
  (let* ((proc (get-buffer-process buffer))
         (instance (replace-regexp-in-string
                    "\\`\\*ob-axiom:\\(.*\\)\\*\\'" "\\1" (buffer-name buffer)))
         (label (car (split-string body "\n")))
         (baseline (or (ob-axiom--last-prompt-number buffer) 0))
         (target (+ baseline (max 1 (ob-axiom--count-statements body))))
         (start (with-current-buffer buffer (point-max)))
         (r (progn (process-send-string proc (ob-axiom--wrap-show body show))
                   (ob-axiom--session-wait proc ob-axiom-session-timeout target)))
         (slice (if (buffer-live-p buffer)
                    (with-current-buffer buffer
                      (buffer-substring-no-properties start (point-max)))
                  "")))
    (if (numberp r)
        (progn (ob-axiom--log instance label slice)
               slice)
      (ob-axiom--log instance (format "ABORTED (%s) %s" r label) slice)
      (let ((kill-buffer-query-functions nil))
        (when (buffer-live-p buffer) (kill-buffer buffer)))
      (format "ob-axiom: session aborted (%s); re-run for a fresh session" r))))

(defun ob-axiom-kill-session (session)
  "Kill the Axiom comint SESSION and forget it."
  (interactive
   (list (completing-read "Kill Axiom session: "
                          (hash-table-keys ob-axiom--sessions) nil t)))
  (let ((buf (gethash session ob-axiom--sessions))
        (kill-buffer-query-functions nil))
    (when (buffer-live-p buf) (kill-buffer buf))
    (remhash session ob-axiom--sessions)))

(defun ob-axiom-kill-all-sessions ()
  "Kill every Axiom comint session."
  (interactive)
  (let ((kill-buffer-query-functions nil))
    (maphash (lambda (_ buf) (when (buffer-live-p buf) (kill-buffer buf)))
             ob-axiom--sessions))
  (clrhash ob-axiom--sessions))
#+end_src

* Roadmap

| Stage | Deliverable                                                          | State |
|-------+---------------------------------------------------------------------+-------|
| M1    | One-shot pipe: execute → capture TeX → =\[...\]= rendered by preview  | done  |
| M2    | Persistent comint session; variables/types shared across blocks     | done  |
| M3    | Multi-line/continuation input; abort-on-hang; =:show= toggle in session | done  |
| M4    | =axiom-mode= font-lock; cache + async via Org's own machinery        | done  |
| M5    | Per-instance verbose logs; one-shot stderr separation; timeout evidence | done  |

Deferred (not speculative work until a real need appears): regenerating the
full =axiom.vim= domain/operation/category/package tables into font-lock; and
SIGINT-based session recovery (the current abort-on-hang kills the session,
which is simpler and deterministic).

* Rejected Alternatives

- *Translate OutputForm to LaTeX in Elisp.* Rejected: duplicates
  =TexFormat= and would drift from Axiom's own rendering. The contract is to
  use Axiom's TeX output verbatim.
- *Parse results by prompt regex only* (the legacy =axiom.el= approach).
  Kept as a fallback idea for sessions but not primary: bare =^(N) -> =
  matching is fragile against multi-line output and banner noise; the bare
  =$$= delimiters are exact.
- *Default to a persistent session now.* Deferred: a half-built comint sync
  risks a flaky E2E. One-shot is correct first; the session is an
  optimisation layered on a working pipeline.

(defconst ob-axiom-test--goto-fixture
  (concat ")abbrev domain FOO FooDomain\n"
          "FooDomain() : SIG == CODE where\n"
          "  SIG ==> OrderedSet with\n"
          "    introduce! : (Symbol,Symbol) -> Union(%, \"failed\")\n"
          "      ++X introduce!(t,dt)\n"
          "  CODE ==> Symbol add\n"
          "    introduce!(X,dX) ==\n"
          "      42\n")
  "A minimal .spad shape: signature (no ==), ++X doc, capsule == line.")

(defmacro ob-axiom-test--with-goto-fixture (var &rest body)
  "Run BODY with VAR bound to a temp .spad file of the goto fixture."
  `(let ((,var (make-temp-file "ob-axiom-goto-" nil ".spad"
                               ob-axiom-test--goto-fixture)))
     (unwind-protect (progn ,@body)
       (let ((b (find-buffer-visiting ,var))) (when b (kill-buffer b)))
       (delete-file ,var))))

(ert-deftest ob-axiom-test-goto-definition-op-line ()
  "An operation jump lands on the capsule == line, not sig or doc lines."
  (ob-axiom-test--with-goto-fixture f
    (axiom--locate-definition "FooDomain" "FOO" f "introduce!")
    (should (looking-at "[ \t]*introduce!(X,dX) =="))
    (should (= 7 (line-number-at-pos)))))
